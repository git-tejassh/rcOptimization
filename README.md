# Surrogate-assisted cost / embodied-carbon optimisation of an RC frame (IS 456, gravity only)

Final-year B.Tech Civil major project (7th semester), MANIT Bhopal. OpenSeesPy-generated data, XGBoost surrogates, constrained NSGA-II (pymoo),
Pareto front, FE re-verification, and a static dashboard. Validated against the owner's STAAD.Pro model (reactions to 1e-5, column moments to 0.12 %).

> **Caveats you must read:** designs are checked for **gravity loading only** (no seismic / wind); cost rates and several carbon inputs are
> provisional, IS 456 tables are transcribed from memory and need checking against the printed code (`docs/ASSUMPTIONS.md`).
> No novelty of algorithm is claimed (NSGA-II for RC frames: Kaveh et al., 2016); the contribution is a validated, India-contextualised application.

## Quick start (Windows PowerShell; Python 3.12)
```powershell
.\make.ps1 setup          # venv + pinned requirements + npm install
.\make.ps1 all            # phase0 .. phase5, sensitivity, report, export   (about 2 h on a laptop)
cd web; npm run build     # then open web/dist/index.html (single file, works by double-click)
```
Per-phase commands: `.venv\Scripts\python.exe -m rcopt.cli phase0 | phase0b | phase1 | ... | phase5 | sensitivity | report | export`.
Tests: `.venv\Scripts\python.exe -m pytest` (`-m "not slow"` for the fast set).

## Dashboard tabs
Layout: one hero (the page's single title) per tab, header menus Overview / Designs / Method / Data / Live evaluator plus a green "My design estimate" button. Overview · Design space · Pareto explorer (bad/good/best zones, full property sheet, best-case cards) · Surrogate performance · Verification · Compute comparison · Sensitivity (incl. cement type) · Data & assumptions · Live evaluator (needs `make api`) · About · **My design estimate** (upload a STAAD `.std`, or start from an optimised design, edit every price / carbon factor, get quantities, cost, carbon and a comparison with the optimiser; browser-only, no strength check).

## Where things are
| Path | What |
|---|---|
| `config/*.yaml` | every tunable (design space, loads, rates, factors, GA, seeds) |
| `src/rcopt/` | geometry, fe, codes (IS 456), design, sampling, cost_carbon, surrogate, optimize, verify, report |
| `data/results/` | small result files that feed the dashboard (committed) |
| `web/` | Vite + React dashboard; `web/public/data/*.json` are exported results |
| `api/` | optional local FastAPI (live surrogate / FE evaluation) |
| `docs/` | `REPORT_DRAFT.md`, `BENCHMARK.md`, `ASSUMPTIONS.md`, `DECISIONS.md`, `STANDARDS_COMPLIANCE.md`, `CARBON_DATA_AUDIT.md`, `VIVA_PREP.md`, `DEPLOY.md` |
| `legacy/` | the owner's original files, untouched (STAAD text inputs, old optimiser) |
